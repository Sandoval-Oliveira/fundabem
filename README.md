# Fundabem — ferramentas

Soluções web da Fundação Pato-branquense do Bem-Estar (Fundabem), Pato Branco/PR.
Publicado no Cloudflare Pages a cada push na `main` (site estático, sem build).

| Pasta | Ferramenta |
|---|---|
| `orcamento/` | Gerador de orçamento (pesquisa de preço) em PDF no modelo padrão |

Cada ferramenta fica em sua própria pasta, com um `index.html` autossuficiente.
